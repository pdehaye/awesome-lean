# Contribution Guidelines

Suggestions are welcome! Please make sure your pull request follows these guidelines:

- Search the list first to avoid duplicates.
- Use the format `[Name](link) - Description.`
- Add new entries to the bottom of the relevant section.
- Keep descriptions short and factual: start with a capital letter, end with a period, and avoid marketing taglines.
- Check that links work and point to the canonical page or repository.
- Run `npx awesome-lint` before opening the pull request.
- If you changed `README.md`, regenerate the repository table with `python3 scripts/repos_csv.py` and commit `repos.csv` too. CI checks that it is up to date.

Thank you for contributing!
